# FUTURE_ML_02
# Support Ticket Classification System

## Internship
Future Interns - Machine Learning

## Objective
To automatically classify customer support tickets into predefined categories using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Features
- Text preprocessing
- Ticket classification
- Category prediction
- Data visualization

## Workflow
1. Data Collection
2. Data Cleaning
3. Feature Extraction using TF-IDF
4. Model Training
5. Prediction
6. Evaluation

## Results
The model successfully classifies support tickets into categories such as:
- Billing
- Refund
- Technical
- Login
- Delivery
- Subscription

- Natural Language Processing
- Machine Learning
